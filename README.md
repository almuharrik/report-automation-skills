# Report Automation Skills

A private library of skills and guides for report automation (decks, recaps, dashboards, data pulls).

## Skills

| Folder | What it is |
|---|---|
| [`not-ai-decks/`](not-ai-decks/) | Rules for building slide decks that don't look AI-generated: 30 common tells, fixes, a pre-presentation checklist, and a copy-paste prompt. Source: Analyst Academy. |

## Adding a new skill

1. Create a new folder named after the skill (lowercase, dashes), e.g. `weekly-recap/`.
2. Put the skill's files inside it (a `SKILL.md` for Claude Code skills, or a guide `.md`).
3. Add a row to the table above.
