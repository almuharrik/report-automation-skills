# report-automation-skill

Data collector for the monthly Haydecor Ads Performance Report.

- `SKILL.md`: the agent instructions. Inputs, steps, calculations, output (Data Pack), rules.
- `docs/CHECKS.md`: verification checks with tolerances.
- `docs/VALIDATION_2026-10.md`: results of the first run (October 2026) and open items. Contains October revenue and spend figures for reference.

Monthly raw data lives in `raw_data/YYYY-MM_ReportData/` in the data repo (`almuharrik/report-automation`). This repo holds instructions and validation notes only. It contains no credentials, Apps Script URLs, spreadsheet IDs or HAR files.
